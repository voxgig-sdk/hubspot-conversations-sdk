Make your first API call

  1. Choose an SDK from the SDK section and follow its installation instructions.
  2. Configure the API server and authentication settings.
  3. Open the Channel reference and supply the parameters and request body it requires.
  4. Call remove and inspect the returned entity data.

The first endpoint is DELETE /conversations/custom-channels/2026-09/{channelId}. Request and response examples come from the model.
